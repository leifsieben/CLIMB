## SI · Synthetic-statistics ladder: which corpus statistic carries the MLM benefit?

Pretraining corpora that preserve progressively **less** structure, each bit-identical to the
`unsup_8M` setup except for the corpus itself, then frozen-probed (5-fold scaffold CV, 3 seeds):

- **real** — the actual PubChem SMILES corpus.
- **shuffle tokens** — each molecule's tokens randomly permuted: destroys token **order** but keeps
  its per-molecule token **multiset** (composition).
- **unigram resample** — each sequence redrawn i.i.d. from the corpus token marginal: keeps only the
  **corpus-level token frequencies**, destroys per-molecule composition.
- **no_pretrain (frozen)** — random init; the 0-lift reference.

Bars are lift over the random-init floor. If token **order** carried the benefit, *shuffle* would
collapse to the floor; if only the corpus **marginal** mattered, *unigram* would recover it. Neither
happens: **shuffle ≈ real** and **unigram ≈ no_pretrain**, uniformly across all seven tasks. So the
MLM benefit lives in **per-molecule token composition** — which tokens co-occur within a molecule —
not their sequence and not their corpus frequency. HIV is scored by ROC-AUC here (shared with the
other classification tasks); NEF1% is its headline elsewhere.
