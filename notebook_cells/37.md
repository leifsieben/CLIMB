## SI · Synthetic-statistics ladder: which corpus statistic carries the MLM benefit?

Pretraining corpora that preserve progressively **less** structure, each bit-identical to the
`unsup_8M` setup except for the corpus itself, then frozen-probed (5-fold scaffold CV, 3 seeds):

- **real** — the actual PubChem SMILES corpus.
- **shuffle tokens** — each molecule's tokens randomly permuted: destroys token **order** but keeps
  its per-molecule token **multiset** (composition).
- **bigram resample** — each sequence redrawn from the corpus **bigram** model: keeps local
  token-to-token **adjacency**, but not the molecule's full multiset.
- **unigram resample** — each sequence redrawn i.i.d. from the corpus token marginal: keeps only the
  **corpus-level token frequencies**.
- **no_pretrain (frozen)** — random init; the 0-lift reference.

Bars are lift over the random-init floor. The dominant effect is **per-molecule composition**:
**shuffle ≈ real** (order barely matters) and **unigram ≈ no_pretrain** (the corpus marginal buys
nothing). **Bigram sits genuinely between** unigram and shuffle on the tasks with real spread
(ESOL, BACE, Tox21, Lipophilicity), so **local token adjacency carries a partial, task-dependent
share** — it is not nothing, but it does not close the composition gap. On the saturated tasks
(BBBP, HIV) all arms cluster within noise, so the ladder is most legible on ESOL/Lipo/BACE/Tox21/QM7.
HIV is scored by ROC-AUC here (NEF1% is its headline elsewhere).
